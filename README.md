# ACE Atlas

Constructing semantic fields for reliable language models.

ACE Atlas is the research layer of the ACE project. It builds contextual semantic fields using anchors, embeddings, context matrices, SVD subspaces, origin cost, margin, density, and stability metrics.

## Repository role

- ACE Atlas: semantic field construction, benchmarks, methodology, research logs.
- ACE Semantic Gateway: runtime firewall, API routing, inference policy, LLM orchestration.

## Core pipeline

anchors → embeddings → context matrix → SVD basis → origin cost → margin → density → stability index
